# Musbat va manfiy elementlar soni

## THEORY

Bu — amaliy mashq masalasi (Abramyan to'plamidan, Array bo'limi). Yangi Go tushunchasi emas, balki oldin o'rgangan bilimlaringizni mustahkamlash uchun mo'ljallangan.

Qiyinlik: **O'rta** · Ball: **10** · Taxminiy vaqt: **6 daqiqa**

## EXAMPLE

```
Input: N=6, arr=[3,-7,2,-9,1,8]
Output: pos=4, neg=2
```

## TASK

N ta elementli massiv berilgan. Musbat va manfiy elementlar sonini toping.

Quyidagi funksiyani to'ldiring:

```go
func countPosNeg(N int, arr []int) string {
    // ...
}
```

Vim editorini ochish uchun ENTER bosing. Kod tayyor bo'lgach, **`:wqa`** (yoki `:xa`) buyrug'i bilan chiqing — ikkita oyna (dars matni + kod) ochiq bo'lgani uchun oddiy `:q` faqat bittasini yopadi va kodni saqlamaydi.

## HINTS

1. Massiv elementlarini aylanib o'ting
2. Index bilan ishlaganda ehtiyot bo'ling
