# Selection Sort

## THEORY

Bu — amaliy mashq masalasi (Abramyan to'plamidan, Array bo'limi). Yangi Go tushunchasi emas, balki oldin o'rgangan bilimlaringizni mustahkamlash uchun mo'ljallangan.

Qiyinlik: **Qiyin** · Ball: **15** · Taxminiy vaqt: **12 daqiqa**

## EXAMPLE

```
Input: N=5, arr=[5,2,8,1,9]
Output: [9,8,5,2,1]
```

## TASK

N ta elementli massiv berilgan. Selection sort algoritmi bilan kamayish tartibida saralang.

Quyidagi funksiyani to'ldiring:

```go
func selectionSort(N int, arr []int) []int {
    // ...
}
```
