# To'g'ri burchakli uchburchak

## THEORY

Bu — amaliy mashq masalasi (Abramyan to'plamidan, Begin bo'limi). Yangi Go tushunchasi emas, balki oldin o'rgangan bilimlaringizni mustahkamlash uchun mo'ljallangan.

Qiyinlik: **O'rta** · Ball: **10** · Taxminiy vaqt: **7 daqiqa**

## EXAMPLE

```
Input: a=3, b=4
Output: c=5
```

## TASK

To'g'ri burchakli uchburchakning katetlari berilgan. Gipotenuzasini toping.

Quyidagi funksiyani to'ldiring:

```go
func uchburchak(a int, b int) int {
    // ...
}
```

Vim editorini ochish uchun ENTER bosing. Kod tayyor bo'lgach, **`:wqa`** (yoki `:xa`) buyrug'i bilan chiqing — ikkita oyna (dars matni + kod) ochiq bo'lgani uchun oddiy `:q` faqat bittasini yopadi va kodni saqlamaydi.

## HINTS

1. Pifagor: c² = a² + b²
2. c = sqrt(a*a + b*b)
