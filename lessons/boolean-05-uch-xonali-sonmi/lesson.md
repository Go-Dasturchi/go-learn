# Uch xonali sonmi

## THEORY

Bu — amaliy mashq masalasi (Abramyan to'plamidan, Boolean bo'limi). Yangi Go tushunchasi emas, balki oldin o'rgangan bilimlaringizni mustahkamlash uchun mo'ljallangan.

Qiyinlik: **Oson** · Ball: **5** · Taxminiy vaqt: **4 daqiqa**

## EXAMPLE

```
Input: A=123
Output: true
```

## TASK

Butun son A berilgan (A > 0). 'A uch xonali son' degan tasdiqni tekshiring.

Quyidagi funksiyani to'ldiring:

```go
func isThreeDigit(A int) bool {
    // ...
}
```

Vim editorini ochish uchun ENTER bosing. Kod tayyor bo'lgach, **`:wqa`** (yoki `:xa`) buyrug'i bilan chiqing — ikkita oyna (dars matni + kod) ochiq bo'lgani uchun oddiy `:q` faqat bittasini yopadi va kodni saqlamaydi.

## HINTS

1. true yoki false qaytaring
2. Mantiqiy operatorlar: &&, ||, !
