# Yo'nalishni aniqlash

## THEORY

Bu — amaliy mashq masalasi (Abramyan to'plamidan, Case bo'limi). Yangi Go tushunchasi emas, balki oldin o'rgangan bilimlaringizni mustahkamlash uchun mo'ljallangan.

Qiyinlik: **O'rta** · Ball: **10** · Taxminiy vaqt: **7 daqiqa**

## EXAMPLE

```
Input: N1=1, K=1
Output: Sharq
```

## TASK

N1 (1-Shimol, 2-G'arb, 3-Janub, 4-Sharq) va burilish K berilgan. Yangi yo'nalishni toping.

Quyidagi funksiyani to'ldiring:

```go
func getDirection(N1 int, K int) string {
    // ...
}
```

Vim editorini ochish uchun ENTER bosing. Kod tayyor bo'lgach, **`:wqa`** (yoki `:xa`) buyrug'i bilan chiqing — ikkita oyna (dars matni + kod) ochiq bo'lgani uchun oddiy `:q` faqat bittasini yopadi va kodni saqlamaydi.

## HINTS

1. switch operatoridan foydalaning
2. Har bir case uchun break qo'yishni unutmang
