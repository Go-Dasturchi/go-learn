# Teapot

## THEORY

Bu — amaliy mashq masalasi (LeetCode to'plamidan, Easy daraja). Yangi Go tushunchasi emas, balki oldin o'rgangan bilimlaringizni mustahkamlash uchun mo'ljallangan.

Qiyinlik: **Oson** (Easy) · Ball: **10** · Taxminiy vaqt: **10 daqiqa**

## EXAMPLE

```
Input: a = 12, b = 8
Output: 4
Tushuntirish: 12 va 8 ning GCD si 4.
```

## TASK

Sizga ikki butun son `a` va `b` berilgan. Ularning eng katta umumiy bo'luvchisini (GCD — Greatest Common Divisor) toping.

**GCD** — bu ikki sonni qoldiqsiz bo'la oladigan eng katta son.

Quyidagi funksiyani to'ldiring:

```go
func solve(a int, b int) int {
    // ...
}
```

Vim editorini ochish uchun ENTER bosing. Kod tayyor bo'lgach, **`:wqa`** (yoki `:xa`) buyrug'i bilan chiqing — ikkita oyna (dars matni + kod) ochiq bo'lgani uchun oddiy `:q` faqat bittasini yopadi va kodni saqlamaydi.

## HINTS

1. Masala shartini qayta o'qib, kerakli algoritmni aniqlang.
2. Avval eng oddiy (naiv) yechimni yozing, keyin kerak bo'lsa optimallashtiring.
