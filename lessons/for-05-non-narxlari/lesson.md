# Non narxlari

## THEORY

Bu — amaliy mashq masalasi (Abramyan to'plamidan, For bo'limi). Yangi Go tushunchasi emas, balki oldin o'rgangan bilimlaringizni mustahkamlash uchun mo'ljallangan.

Qiyinlik: **Oson** · Ball: **5** · Taxminiy vaqt: **4 daqiqa**

## EXAMPLE

```
Input: A=5
Output: 6.0, 7.0, 8.0, 9.0, 10.0
```

## TASK

Non narxi A (1.2, 1.4, ..., 2.0 kg uchun). Har biri uchun narxni chiqaring.

Quyidagi funksiyani to'ldiring:

```go
func breadPrices(A int) string {
    // ...
}
```

Vim editorini ochish uchun ENTER bosing. Kod tayyor bo'lgach, **`:wqa`** (yoki `:xa`) buyrug'i bilan chiqing — ikkita oyna (dars matni + kod) ochiq bo'lgani uchun oddiy `:q` faqat bittasini yopadi va kodni saqlamaydi.

## HINTS

1. for siklidan foydalaning
2. Parametrni to'g'ri sozlang
