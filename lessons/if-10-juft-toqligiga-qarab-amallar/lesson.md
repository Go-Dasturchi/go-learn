# Juft-toqligiga qarab amallar

## THEORY

Bu — amaliy mashq masalasi (Abramyan to'plamidan, If bo'limi). Yangi Go tushunchasi emas, balki oldin o'rgangan bilimlaringizni mustahkamlash uchun mo'ljallangan.

Qiyinlik: **O'rta** · Ball: **10** · Taxminiy vaqt: **6 daqiqa**

## EXAMPLE

```
Input: A=4, B=6
Output: 5.0
```

## TASK

Ikkita son A va B berilgan. Agar ikkalasi ham juft bo'lsa o'rta arifmetik, aks holda o'rta geometrik toping.

Quyidagi funksiyani to'ldiring:

```go
func evenOddAction(A int, B int) float64 {
    // ...
}
```

Vim editorini ochish uchun ENTER bosing. Kod tayyor bo'lgach, **`:wqa`** (yoki `:xa`) buyrug'i bilan chiqing — ikkita oyna (dars matni + kod) ochiq bo'lgani uchun oddiy `:q` faqat bittasini yopadi va kodni saqlamaydi.

## HINTS

1. if-else operatoridan foydalaning
2. Shartlarni to'g'ri tekshiring
