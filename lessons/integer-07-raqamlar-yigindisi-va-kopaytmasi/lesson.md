# Raqamlar yigindisi va ko'paytmasi

## THEORY

Bu — amaliy mashq masalasi (Abramyan to'plamidan, Integer bo'limi). Yangi Go tushunchasi emas, balki oldin o'rgangan bilimlaringizni mustahkamlash uchun mo'ljallangan.

Qiyinlik: **Oson** · Ball: **5** · Taxminiy vaqt: **4 daqiqa**

## EXAMPLE

```
Input: n=23
Output: 5
```

## TASK

Ikki xonali son berilgan. Raqamlarining yig'indisini toping.

Quyidagi funksiyani to'ldiring:

```go
func sumAndProduct(n int) int {
    // ...
}
```

Vim editorini ochish uchun ENTER bosing. Kod tayyor bo'lgach, **`:wqa`** (yoki `:xa`) buyrug'i bilan chiqing — ikkita oyna (dars matni + kod) ochiq bo'lgani uchun oddiy `:q` faqat bittasini yopadi va kodni saqlamaydi.
