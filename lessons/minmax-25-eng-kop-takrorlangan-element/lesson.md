# Eng ko'p takrorlangan element

## THEORY

Bu — amaliy mashq masalasi (Abramyan to'plamidan, MinMax bo'limi). Yangi Go tushunchasi emas, balki oldin o'rgangan bilimlaringizni mustahkamlash uchun mo'ljallangan.

Qiyinlik: **Qiyin** · Ball: **15** · Taxminiy vaqt: **10 daqiqa**

## EXAMPLE

```
Input: N=8, nums=[3, 5, 3, 7, 3, 9, 5, 3]
Output: element=3, count=4
```

## TASK

N ta son berilgan. Eng ko'p takrorlangan elementni va uning sonini toping.

Quyidagi funksiyani to'ldiring:

```go
func mostFrequent(N int, nums []int) string {
    // ...
}
```

Vim editorini ochish uchun ENTER bosing. Kod tayyor bo'lgach, **`:wqa`** (yoki `:xa`) buyrug'i bilan chiqing — ikkita oyna (dars matni + kod) ochiq bo'lgani uchun oddiy `:q` faqat bittasini yopadi va kodni saqlamaydi.

## HINTS

1. Barcha elementlarni ko'rib chiqing
2. Minimal/maksimal qiymatni saqlang
