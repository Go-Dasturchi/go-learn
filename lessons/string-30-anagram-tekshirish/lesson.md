# Anagram tekshirish

## THEORY

Bu — amaliy mashq masalasi (Abramyan to'plamidan, String bo'limi). Yangi Go tushunchasi emas, balki oldin o'rgangan bilimlaringizni mustahkamlash uchun mo'ljallangan.

Qiyinlik: **Qiyin** · Ball: **15** · Taxminiy vaqt: **10 daqiqa**

## EXAMPLE

```
Kiritish: S1='listen', S2='silent'
Chiqish: true
```

## TASK

S1 va S2 satrlar berilgan. Ular anagram (bir xil harflardan iborat) ekanligini tekshiring.

Quyidagi funksiyani to'ldiring:

```go
func solve(s1 string, s2 string) bool {
    // ...
}
```

Vim editorini ochish uchun ENTER bosing. Kod tayyor bo'lgach, **`:wqa`** (yoki `:xa`) buyrug'i bilan chiqing — ikkita oyna (dars matni + kod) ochiq bo'lgani uchun oddiy `:q` faqat bittasini yopadi va kodni saqlamaydi.

## HINTS

1. String metodlaridan foydalaning
2. Looplar yordamida belgilarni aylanib o'ting
