# Sonni teskari o'qish

## THEORY

Bu — amaliy mashq masalasi (Abramyan to'plamidan, While bo'limi). Yangi Go tushunchasi emas, balki oldin o'rgangan bilimlaringizni mustahkamlash uchun mo'ljallangan.

Qiyinlik: **O'rta** · Ball: **10** · Taxminiy vaqt: **8 daqiqa**

## EXAMPLE

```
Input: N=12345
Output: 54321
```

## TASK

N > 0 berilgan. Raqamlarni o'ngdan chapga o'qib yangi son hosil qiling.

Quyidagi funksiyani to'ldiring:

```go
func reverseNum(N int) int {
    // ...
}
```

Vim editorini ochish uchun ENTER bosing. Kod tayyor bo'lgach, **`:wqa`** (yoki `:xa`) buyrug'i bilan chiqing — ikkita oyna (dars matni + kod) ochiq bo'lgani uchun oddiy `:q` faqat bittasini yopadi va kodni saqlamaydi.
